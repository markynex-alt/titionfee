# Tuition Fee Manager - Official WordPress Theme & Subscription Website

This directory contains the complete, production-ready WordPress theme and standalone web storefront for **Tuition Fee Manager**.

---

## 📦 What's Inside

| File / Folder | Description |
|---|---|

| **`index.html`** | Standalone, self-contained single-page web app for static hosting (Netlify, Vercel, GitHub Pages) or offline browsing. |

## 🚀 1-Click WordPress Installation

1. Log in to your WordPress Admin dashboard (`/wp-admin`).
2. Navigate to **Appearance** → **Themes** → **Add New** → **Upload Theme**.
3. Choose the file: `G:\Flutter_Projects\tuitionfee\website\tuition-theme.zip`.
4. Click **Install Now**, then click **Activate**.
5. That's it! Your site will now display the modern Tuition Fee subscription storefront.

## ⚙️ WordPress Admin Features

### 1. Tuition Plans (`wp-admin > Tuition Plans`)
- Three default plans are seeded automatically:
  - **Starter Plan**: 5 Batches & 10 Students = ৳30/month
  - **Standard Plan**: 10 Batches & 20 Students = ৳50/month (Highlighted / Most Popular)
  - **Unlimited Pro**: Unlimited Batches & Students = ৳200/month
- Add or edit any plan: change monthly price (৳), batch quota (-1 for unlimited), student capacity (-1 for unlimited), feature checklist, and badges.

### 2. Tuition Orders & License Records (`wp-admin > Tuition Plans > All Orders & Licenses`)
- Every purchase submitted by a user is saved in the WordPress database.
- Displays: Customer Name, Phone, Email, Amount Paid, TrxID, Payment Method, Date, and the **Generated License Key** with 1-click copy.

### 3. Store & Cryptographic Settings (`wp-admin > Settings > Tuition Store`)
- **bKash / Nagad Receiver Number**: Customize the mobile banking account shown at checkout (default: `01825690912`).
- **Secret Hash Salt**: Configure the SHA-256 salt (default: `TUITION_FEE_AUTH_SALT_01825690912`), matching Flutter `lib/services/license_service.dart`.
- **Discounts**: Set percentage discounts for 3 Months (5%), 6 Months (10%), and 12 Months (20%).
- **Live Key Tester**: Test generating authentic keys directly in the admin panel to test in the Flutter mobile app!

## 🔒 100% Cryptographic App Synchronization

Every license generated by this WordPress theme matches the Flutter app's offline SHA-256 verification algorithm:

```
Format: TF-<TIER>-<MONTHS>M-<CHECKSUM>
Checksum: strtoupper(substr(sha256("TUITION_FEE_AUTH_SALT_01825690912:<TIER>:<MONTHS>"), 0, 4))
```

### Examples:
- **Starter (1 Month)**: `TF-STARTER-1M-4952`
- **Standard (3 Months)**: `TF-STANDARD-3M-8558`
- **Unlimited (12 Months)**: `TF-UNLIMITED-12M-6D43`

Users can enter any generated code into **TuitionFee App** → **Settings** → **Subscription & Plans** → **Enter Activation Code** → **Activate** to immediately unlock their quota and validity.
