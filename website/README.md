# Tuition Fee Manager - Official eCommerce & Subscription Website

This directory contains the modern, responsive, clean WordPress & eCommerce website for Tuition Fee Manager subscription plans.

---

## 🌟 Features Included

1. **Modern, Responsive & Clean UI**:
   - Built with Tailwind CSS, Plus Jakarta Sans typography, and clean cards.
   - Fully optimized for desktop, tablets, and smartphones.
2. **The 3 Editable Subscription Plans**:
   - **Free Tier**: Up to 5 Batches and 10 Students (0 Taka / Free forever).
   - **Plan 1 (Starter)**: 5 Batches & 10 Students = **30 Taka / month**.
   - **Plan 2 (Standard)**: 10 Batches & 20 Students = **50 Taka / month** (Most Popular).
   - **Plan 3 (Unlimited Pro)**: Unlimited Batches & Unlimited Students = **200 Taka / month**.
3. **Multi-Month Duration Multiplier**:
   - Users can select **1 Month**, **3 Months** (5% discount), **6 Months** (10% discount), or **12 Months** (20% discount).
   - Prices dynamically calculate and update in Bangladeshi Taka (৳).
4. **Checkout & License Delivery**:
   - Accepts bKash, Nagad, Rocket, or Bank Cards.
   - Generates official activation keys (e.g. `TF-STARTER-3M-A98B`, `TF-STANDARD-6M-E12C`, `TF-UNLIMITED-12M-991E`).
   - Customers simply copy the key and enter it into the mobile app's **Settings -> Subscription & Plans -> Enter Activation Code** to immediately unlock their tier!
5. **Interactive Admin Plan Editor**:
   - Click **Edit Plans (Admin)** in the top navigation.
   - Edit Plan Name, Monthly Price in Taka, Max Batches, and Max Students.
   - Click **Save All Changes** to immediately update the live website storefront.

## 🚀 How to Run & Deploy

### Option 1: Standalone Web App / Direct Browser (Instant)
- Simply double-click `index.html` or open it with any web browser.
- You can host it directly on **GitHub Pages**, **Netlify**, **Vercel**, or any static web host.

### Option 2: WordPress Theme Installation
1. Zip this entire directory `tuition_website` as `tuition-theme.zip`.
2. In your WordPress Admin Dashboard, go to **Appearance -> Themes -> Add New -> Upload Theme**.
3. Upload `tuition-theme.zip` and click **Activate**.
4. You will see **Tuition Plans** and **Tuition Orders** in your WordPress admin menu.
